# Security Policy

## Supported Versions

Only the latest version of the Shimmer reader is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in the Shimmer reader or any related
component, please report it by opening an issue on the GitHub repository:

https://github.com/bestdeejay-design/shimmer/issues

Please do not report security vulnerabilities through public GitHub discussions
or other public channels.

We will acknowledge receipt of your report within 48 hours and provide an
estimated timeline for a fix.
