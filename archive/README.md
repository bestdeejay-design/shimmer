# Archive — черновики и вспомогательные материалы

Эта папка **не участвует в сборке сайта** (mdBook берёт исходники только из `files/`).
Сюда перенесено всё, что не нужно для публикации, но сохранено на всякий случай.

## Структура

```
archive/
├── drafts/                    # Черновики глав (старые версии, не в сборке)
│   ├── kai/                   #   Кай: отдельные главы + папка book/ (полная ранняя версия)
│      └── book/                #     Книга Кая целиком (doc-версия) + Структура_МЕРЦАНИЕ.md
│   └── lira/                  #   Лира: папка book/ (ранние/альтернативные версии глав)
│
├── old-root-drafts/lore/      # Дубликаты лора с корня проекта (до переноса в files/lore).
│                              # Сохранены как tracked-файлы — возможно, отличаются от files/lore.
│
├── translations/lira-en/working/  # Рабочие EN-переводы Книги Лиры (черновики тулинга, не в сборке)
│
├── reference/                 # Справочники и заметки по вселенной
│   ├── UNIVERSE.md            #   (бывший корень) — описание вселенной
│   ├── CHAT_DIGEST.md         #   (бывший корень) — выжимка чатов
│   ├── Структура_МЕРЦАНИЕ.md  #   структура саги
│   ├── glossary.md            #   глоссарий
│   └── 17851881527abf.png     #   арт-референс
│
├── tooling/                   # Мусор инструментов (не по делу проекта)
│   ├── playwright-mcp/        #   логи/скриншоты Playwright MCP
│   ├── omo/                   #   сессии run-continuation (.omo)
│   └── chat-export-*.json     #   экспорт чата (огромный)
│
└── files (3).zip              # Случайный zip-архив
```

## Что НЕ трогать (участвует в сборке)
- `files/` — RU+EN книги Кая/Лиры + лора + SUMMARY.md
- `theme/`, `custom/` — оформление
- `book.toml`, `book.en.toml` — конфиги mdBook
- `.github/workflows/deploy.yml` — автодеплой на GitHub Pages

> Все файлы из этой папки можно удалить без вреда для сайта, но пока оставлены «на память».
