# Contributing to Shimmer

Thank you for considering contributing to the Shimmer universe!

## How to Contribute

### Reporting Issues

- **Content errors**: If you find inconsistencies, typos, or logic gaps in the
  story, open an issue with the chapter reference.
- **Reader bugs**: If the mdBook reader behaves unexpectedly (broken layout,
  missing navigation, etc.), include your browser and device info.
- **Lore questions**: Use issues for universe‑building discussions.

### Suggesting Changes

1. Fork the repository.
2. Create a branch for your change (`git checkout -b fix/...`).
3. Commit your changes with a clear message.
4. Open a pull request.

### Code Style

- **Markdown files**: Keep lines reasonably short (80–100 chars). Use ATX
  headings (`#`, `##`, …). No trailing spaces.
- **JavaScript** (`custom/custom.js`): ES5 compatible (no transpiler).
  `'use strict'`; IIFE‑wrapped modules. No external dependencies.
- **CSS** (`custom/custom.css`): Organise by feature with section
  comments. Prefer CSS custom properties.

## What Not to Do

- Do not introduce AI‑generated content without review.
- Do not change the core lore without opening a discussion first.
- Do not commit generated files (`book/html/`, `book/epub/`).

## Contact

Open an issue or start a discussion on GitHub.
